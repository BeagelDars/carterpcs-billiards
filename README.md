# 🎱 CarterPCs Billiards

A minimalist, cartoonish light-themed 8-ball billiards web game featuring CarterPCs as the billiard balls, played against an AI bot ("CarterBot") with real open-source acoustic pool sound effects.

## Features
- **Crystal-Clear Carter Balls**: All 16 balls feature Carter's smiling face clipped into spheres with 3D glossy highlights, top badges, and billiard color grading.
- **Turn-based 8-Ball against CarterBot**: Smart shot calculation with real-time cue aiming and pullback.
- **Real Open-Source Audio**: Real recorded physical pool sounds for ball collisions, cue strikes, cushion bounces, and pocket drops.
- **Minimalist Light Design**: Clean, distraction-free modern interface.
